# 🍔 皮老闆的秘方爭奪戰

> 期末專題 · Unity 2D 小遊戲

---

## 📖 遊戲介紹

皮老闆決定趁蟹老闆不注意，偷走蟹堡王的神秘配方！

玩家扮演皮老闆，必須躲開廣場上游蕩的海綿寶寶與派大星、穿越車水馬龍的危險馬路、再闖過蟹堡王內部的重重機關，成功帶著秘方逃回海霸王。

* **遊戲類型** ：2D Top-down 動作過關
* **操作方式** ：方向鍵控制皮老闆上下左右移動（格子跳動）
* **勝利條件** ：拿到秘方後，安全返回起點，觸發勝利畫面「凱倫，我成功了！」
* **失敗條件** ：碰到障礙物後，從最近的存檔點重生；紀錄死亡次數

---

## 🗺️ 關卡設計

### 第一關｜廣場直線衝刺：躲避來回障礙

| 項目     | 內容                                                                   |
| -------- | ---------------------------------------------------------------------- |
| 場景     | 蟹堡王門口的開放廣場                                                   |
| 障礙物   | 數個方塊障礙物在固定軌道上左右來回移動（速度固定、路徑單純）           |
| 目標     | 從廣場下方出發，穿越所有障礙物，抵達上方的蟹堡王大門                   |
| 製作重點 | 障礙物只需設定單軸來回移動，不需要任何物理運算，是最容易實作的關卡類型 |

---

### 第二關｜危險馬路：跨越車流

| 項目     | 內容                                                                                         |
| -------- | -------------------------------------------------------------------------------------------- |
| 場景     | 蟹堡王前的多線道馬路                                                                         |
| 障礙物   | 車輛從左或右單方向持續移動，超出畫面後從另一端重置（每排速度不同）                           |
| 目標     | **去程** ：穿越馬路進入蟹堡王拿到秘方 → **回程** ：帶著秘方再次穿越馬路回到起點 |
| 特色     | 拿到秘方後，秘方圖示跟著皮老闆移動，UI 提示切換為「回程模式」                                |
| 製作重點 | 每輛車邏輯相同，只改速度與方向，可以複製貼上快速完成                                         |

---

### 第三關｜蟹堡王廚房旋轉關：動力旋轉棒

| 項目     | 內容                                                                                                                        |
| -------- | --------------------------------------------------------------------------------------------------------------------------- |
| 場景     | 蟹堡王廚房內部                                                                                                              |
| 障礙物   | 數根長棒以中心點為軸持續旋轉，玩家需判斷旋轉空隙穿越每一組旋轉棒                                                            |
| 目標     | 穿越廚房內所有旋轉棒區域，抵達出口逃脫                                                                                      |
| 製作重點 | 旋轉棒只需對物件持續施加旋轉角度（`Transform.Rotate`），是 Unity 中最單純的動態障礙實作，每組只需調整轉速即可做出難度遞進 |

---

## 🔨 實作流程

整體採用  **Unity 2D 專案（Top-down 視角）** ，全程不使用 3D。

### 分工總覽

| 組員 | 負責模組   | 主要產出                                   |
| ---- | ---------- | ------------------------------------------ |
| A    | 核心程式   | 玩家移動邏輯、碰撞後重生、動畫串接         |
| B    | 障礙物機關 | 車輛循環系統、定時伸縮牆、巡邏敵人         |
| C    | 場景與關卡 | 三關地圖搭建、存檔點配置、障礙物擺放       |
| D    | 系統與 UI  | 計時器、死亡次數顯示、開始／勝利畫面、音效 |
